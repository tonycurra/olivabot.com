Software for devices and data

A web app people can log into. A dashboard for sensors you already own. A model that turns photos into labels. All of it on a dedicated server in the EU, which we can also run. Olivabot B.V., Amsterdam. Email services@olivabot.com.

  • A web app. Login, real data, a link you can send. After you pay, the software is yours.
  • A dashboard for hardware you already have. Probes, meters, cameras — numbers and charts. This is the software half of what we built for Mycofarming.
  • Computer vision. Photos or camera frames in, labels and a log out. Fruit and plants (Olivabot Vision), basil stem and leaf on a €20 camera that then moves an arm (Basil Bot), hand and finger landmarks (Madglove), infrared (Mycosense), NDVI maps from a Mavic 3M processed with WebODM on a machine we ran.

A vision model is as good as your labelled photos. We ship confidence scores and an explicit “unclear”. Models that must run on the chip, with no cloud, are on-device AI — same people, on the firmware page.

EU hosting

A dedicated server in the European Union. HTTPS, nightly backups that have been restored, monitoring, security updates, email support on working days. We can sign a processing agreement when we hold data for you.

New features are a separate milestone, quoted before we touch them. You own the application. If you leave, we move it to a server in your name and hand over the keys.

Payments, ledgers, latency

The same code when the job is a ledger or a hot path: something is too slow, something has to be exactly right, or customer data is somewhere it should not be. C++ and Rust in the path that counts. Local models on a machine you control in the EU when a US API is shipping text off the continent.

How we work

Email what it is for, who uses it, and whether there are photos, sensors, or a camera. Two or three sentences is enough. Reply within two working days. Then a written outline, then milestones. Each step is quoted before it starts. Remote. A call if you ask. Email for a quote.
