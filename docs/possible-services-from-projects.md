## From the projects

### Madglove Sense
- Battery firmware on a tight energy budget (ring-scale).
- IMU / motion firmware and onboard movement classification.
- Computer-vision web app (hand landmarks → numbers for therapists).
- Dashboards and analytics for live + stored motion.
- DFM: talking to suppliers (calls, docs) — not running a line.

### Mycosense
- Sensor firmware (water TDS/EC, soil, CO₂ / T / humidity).
- Radios in software: BLE, Wi-Fi, LoRaWAN (always-on outdoor).
- EU cloud + monitoring dashboards.
- IR / camera pipeline (software on images, not selling cameras).

### Gibbon Bot
- Multi-MCU firmware (ESP32, nRF), BLE, battery-first architecture.
- Control software for several arms (decentralized + coordinator).
- Power/compute trade-offs (the firmware page).

### Olivabot Vision
- Edge / lightweight models, split compute (camera vs MCU vs server).
- Photo-in, labels-out (same family as the web-app “photos” extra).
